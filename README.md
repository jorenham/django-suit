**django-suit is abandoned!**

This fork is a quick-and-dirty fix for Django 6.x for
[django-suit V1](https://github.com/darklow/django-suit/tree/master).

It is not recommended to use django-suit in new projects, as it is no longer maintained.
This fork purely exists to provide a temporary solution for existing projects that
rely on django-suit and need Django 6.x support.
